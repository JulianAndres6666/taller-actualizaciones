# Taller — actualizaciones

Este repositorio solo contiene los **paquetes de actualización firmados** del programa Taller
(`Taller-Actualizacion-X.Y.Z.taller`), publicados como *Releases*. No contiene el código del programa
ni datos de ningún taller.

- El programa Taller revisa aquí una vez al día si hay una versión nueva y la instala con un clic.
- Cada paquete va firmado (Ed25519). El programa rechaza cualquier archivo alterado o que no sea oficial,
  aunque se descargue de otro lugar.
- Para instalar Taller por primera vez use el archivo `Taller-Setup-X.Y.Z.exe` de la última Release.
